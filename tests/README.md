# Tests

This folder holds the tests of the scripts in [`scripts/`](../scripts/README.md) and the sheet they run on, for whoever changes those scripts.

| Path                                    | Holds                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| --------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `check-sheets.test.mjs`                 | The tests of the check: the page order, each check on a copy of the fixture sheet that one change breaks, the listing in a git work tree, and the command's output and exit status                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `render-sheets.test.mjs`                | The tests of the renderer: the page order, count and size of the fixture's PDF and PNG, a font from a variable package, the failures on content past the frame, on a font that does not load and on a network request, the characters a page's fonts lack drawn from the fallback fonts, also in generated content with a `font-family` list of its own, those they hold drawn from the page's, and those a later family of a `font-family` list holds drawn from that family before the fallback, the warning on characters that neither covers, in its text, in generated content, in a first letter that `::first-letter` sets apart and past every family a list loads, whether or not a font of the machine holds them, the pass of characters that a later family of a list covers and of those that draw nothing, the text that is not visible left out, the removal of a failed sheet's files, and the command's output, warnings and exit status |
| `font-files.test.mjs`                   | The tests of the font file reader: the PostScript name and the characters of a static font, of a variable font and of one with characters above U+FFFF, and the refusal of a file that is not WOFF2                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `build-site.test.mjs`                   | The tests of the page build: the release lookup with a stubbed fetch, with a release, with none and unreachable, the catalog of the fixture sheet, a root with no sheet and its notice across the page in Chromium, and the built page in Chromium: its dates created and last modified, sorted by last modified and by title and filtered by text and tag, its release line, and, with a release that holds one PDF, its PDF, canvas and release links, its width on a phone, and the tag and language filters by keyboard and from the URL                                                                                                                                                                                                                                                                                                                                                                                                              |
| `prepare-release.test.mjs`              | The tests of the release notes and catalog: the sheets added, changed and removed since a release in a git repository made for the test, a page file that moves from one sheet to another, none changed, the first release with the date each sheet was last modified, the catalog's links and fields at the tag, the refusals, and the command's exit status                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `fixtures/sheets/`                      | A sheets root that holds the fixture sheet, the only content of `fixtures/`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `fixtures/sheets/two-pages-of-squares/` | A sheet that follows [the contract of a sheet folder](../sheets/README.md), two A4 pages in Source Sans 3                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |

The fixture's page files are written for the tests, not by a Design canvas, so Biome formats and lints them as it does every other file.

Run the tests from the root of the repository:

```bash
npm test
```

The tests of the renderer and of the page build launch the browser that `render-sheets.mjs` uses, so Chromium is installed first, as the root README's "Getting started" shows. The summary at the end of the run gives the number of tests that passed and failed; each line of it starts with `ℹ` in a terminal and with `#` where the output goes to a file or a program, as in CI, and as shown here:

```text
# pass 163
# fail 0
```
