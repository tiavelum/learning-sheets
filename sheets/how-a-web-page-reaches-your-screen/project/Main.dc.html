Picture a web page as a shelf you order by post from a distant workshop and have assembled at home. The scene below is that picture; page two gives the facts behind each numbered item.

Find the addressitems 1–6

Browser. Your assistant, who runs the whole errand for you, from the order slip to the finished shelf.

URL. The order slip you hand over: the workshop's name and the catalogue page you want.

Packets. Small envelopes: every letter, even the lookup, travels in one or more of them, each on its own.

Routers. Sorting offices that pass each envelope on to the next office nearer its address.

DNS. The directory desk that finds the workshop's street address from its name, asking one directory after another.

IP address. The workshop's street address; the post delivers only to addresses, never to names.

Connect and lockitems 7–9

TCP connection. A correspondence opened with greetings, in which every envelope is confirmed and lost ones are resent.

TLS certificate. The workshop's ID card, stamped by a notary your assistant trusts; only the true owner can prove it is theirs.

Encryption. A lockbox around each letter that only your assistant and the workshop can open; the post sees the outside.

Orderitems 10–12

HTTP request. The order letter, in the format every workshop uses, naming the page you want.

Web server. The workshop that keeps the catalogue, reads each order and packs the reply.

HTTP response. The reply parcel: a note saying “here it is” or “not found”, then the goods.

Builditems 13–16

HTML. The assembly plan: every part in order, with a list of extra deliveries: chart, instructions, pictures.

CSS. The finish chart: colour, size and position for each kind of part.

JavaScript. Instructions for moving parts, which your assistant carries out to make drawers open and parts change.

Rendering. The assembly: your assistant builds the frame from the plan, fits it to your room and paints it.
