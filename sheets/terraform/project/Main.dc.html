Configuration The office list: it says what the office should contain, such as 12 desks and one phone line, never the steps to get there.

Resource A line on the list for a rented thing, say a desk or 12 alike; the manager rents, changes or returns the real ones to match.

Terraform The facility manager: reads the whole list, works out what has to change and in which order, and has the clerks carry it out.

Provider A clerk hired for one rental company, who knows only that company's order forms and fills them in for the manager.

State The ledger: one entry per rented thing with its contract number, so the manager knows which real desk belongs to which line.

Backend Where the ledger is kept: by default the manager's drawer; for a team, a shared safe whose "in use" tag allows one writer at a time.

Platform API A rental company's counter, the only place where anything is looked up, rented, changed or returned, by clerks or anyone else.

Drift A colleague swaps a desk straight at a counter; at his next check the manager notices and proposes putting it back as the list says.

Your desk: more things you write

Data source

A lookup line for something that already exists, like the shared meeting room: the manager only reads facts about it.

Module

A ready-made kit, "workstation: desk, chair, lamp, phone", that you add to any list as one line and reuse in every office.

Variable

A blank on the list, such as "number of desks: ___", filled in for each office so that one list serves them all.

Output

A line asking the manager to report a fact back once the work is done, such as the new phone number.

The manager's office: the three steps you ask for, in order

init

Run first, and again when clerks, kits or the ledger's place change: the manager hires the clerks, fetches the kits and gets access to the ledger.

plan

The manager checks the ledger against the counters, compares with your list and writes a change list: + rent, ~ change in place, −/+ return and rent anew, − return. Nothing happens yet.

apply

You approve a fresh list or hand in a saved one; the clerks place the orders in the right order and the manager writes every result into the ledger.
