Ask yourself

  1. Is this the real door? A fake site (phishing) looks the same: check the address.
  2. If I lost my phone today, how would I get back in?
  3. Who can open my email? They can reset many other accounts.

Remember

  1. A different password per account, kept in a password manager.
  2. Use passkeys where offered; elsewhere turn on two-step login.
  3. Prefer an authenticator app or security key to text codes.
  4. Guard your email account best: it can reset many others.
  5. Never tell a code or password to anyone who contacts you.
  6. Set up two ways back in before you need them.
